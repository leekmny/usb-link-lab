# iPhone verified assumptions

| Topic | Primary documentation and consequence | Local observation |
| --- | --- | --- |
| USB | [libusbmuxd](https://github.com/libimobiledevice/libusbmuxd) documents the host multiplexing service. [PeerTalk](https://github.com/rsms/peertalk) demonstrates app-level USB forwarding. [Network.framework](https://developer.apple.com/documentation/network/nwparameters/requiredlocalendpoint) exposes the required local endpoint. | The iPhone app binds a foreground IPv4 loopback listener. Paired-device forwarding, host USB selection and cable behavior have their own test gate. |
| Apple APIs | [ExternalAccessory](https://developer.apple.com/documentation/externalaccessory) communicates with supported accessory protocols. [Apple Devices File Sharing](https://support.apple.com/en-us/120402) copies files for supporting apps. | USBLinkLab uses usbmux to reach its custom application socket. |
| Signing | [Apple developer accounts](https://developer.apple.com/help/account/basics/about-your-developer-account/) documents seven-day Personal Team profiles and limits. [Developer Mode](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device) is a separate device setting. | The user has Windows and reports iPhone 17 Pro Max with iOS 27.0.1. Signing, installation and launch require a local session. |
| Toolchain | [GitHub's macOS 15 image](https://github.com/actions/runner-images/blob/main/images/macos/macos-15-Readme.md) documents Xcode 16.4 for device builds and Xcode 26.3 with iOS Simulator 26.2. [The Xcode and SDK agreement](https://images.apple.com/legal/sla/docs/xcode.pdf) restricts Apple software to Apple-branded hardware running macOS and limits redistribution. [xtool](https://github.com/xtool-org/xtool/releases) documents alternative build workflows. | Windows 11 Pro x64 build 26300, Git 2.56.0.windows.4 and GitHub CLI 2.104.0. The active shell has no Swift, Xcode or visible Apple Mobile Device Service. Hosted macOS provides the build SDK. |
| USB ownership | [Microsoft's WSL USB documentation](https://learn.microsoft.com/en-us/windows/wsl/connect-usb) describes how native Windows loses access to an attached USB device and how to detach it from WSL. | No `usbipd` executable was discovered during inventory. |
| Cryptography | [CryptoKit](https://developer.apple.com/documentation/cryptokit), [HKDF](https://www.rfc-editor.org/rfc/rfc5869.html) and [Python AEAD](https://cryptography.io/en/latest/hazmat/primitives/aead/) document the algorithms. SHA-256 detects accidental changes to Plaintext. HMAC provides authentication without confidentiality. | Appendix A and the lab corpus use the agreed bytes. Routing and control authentication are separate from per-item content authentication. |
| Later Pi work | [USB gadget networking](https://www.raspberrypi.com/news/usb-gadget-mode-in-raspberry-pi-os-ssh-over-usb/) documents a USB network adapter. [Linux usbmon](https://docs.kernel.org/usb/usbmon.html) captures host-controller I/O records. | A later relay requires its own USB ownership, power, capture-quality and real-hardware checks. |
| Artifacts | [GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions) describes compute and storage usage. | The repository is public by the user's choice. The workflow retains CI evidence for 14 days. |
