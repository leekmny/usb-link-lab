# USBLinkLab iPhone interface

## Product context

Students in an owned USB laboratory send a local message, photo or file and observe which information the selected mode protects. They need an accurate record of progress and delivery, and a clear way to recover when the phone disconnects or leaves the foreground. Korean is the application default. English is available in Settings.

## Navigation and presentation

The workbench combines the connection and the composer. History holds distinct outgoing and incoming states, and Settings contains pairing, language and collapsible diagnostics. Show the mode alongside the item in every stage. Place the exposure of the next draft directly beneath its mode selector, and preserve the selection on queued items. An authenticated session and completed Plaintext content have distinct labels.

Use the system type ramp, Dynamic Type, standard controls and symbols. The accent colors are dark teal on light backgrounds and bright teal on dark surfaces. Use neutral system content fields and restrained navy surfaces for the connection section. Keep summaries compact and allow long Korean and English text to wrap. Pair status colors with text and symbols. Keep the interaction hierarchy visible at accessibility sizes.

## Implementation decisions

The iPhone floor is iOS 17. The shipping UI uses SwiftUI and local app storage. Test screenshots use labeled synthetic data and a Debug-only launch flag.
